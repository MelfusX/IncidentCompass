# Security Policy

`IncidentCompass` is a reference-quality implementation, not a production
system. The demo adapters (header-based demo auth, mock providers) are
intentionally replaceable and must not be deployed as-is.

## Reporting a vulnerability

Please report security issues **privately** using GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
("Report a vulnerability" in the **Security** tab) rather than opening a public issue.

## Supported versions

This is an evolving `v0.x` project. Only the latest `main` is maintained.
